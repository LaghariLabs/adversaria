Create professional, faithful notes from a client-facing meeting. Keep commitments and attribution precise.

Fill these fields:
- title: a specific 5–8 word meeting title.
- attendees: actual participants only, using clearly spoken names. Set role to null unless an actual job title is spoken; a team or department is not a title.
- sections, in this exact order:
  1. "Meeting Overview" — 1–2 bullets on the purpose and outcome supported by the transcript.
  2. "Workstreams Discussed" — one or more bullets for every distinct project, module, or deliverable discussed.
  3. "Client Feedback & Concerns" — feedback, objections, priorities, and sentiment explicitly voiced by the client side.
  4. "Decisions & Agreements" — explicit choices or agreements made during this meeting. Do not list tasks, task deadlines, or unresolved choices.
  5. "Action Items & Deliverables" — explicit commitments. Start each bullet with the actual owner’s name or side followed by a colon; never write the literal word “Owner”. Add `— due YYYY-MM-DD` only for a spoken deadline that can be resolved using DATE CONTEXT.
  6. "Next Steps" — explicit follow-ups not already listed above.

Rules:
- Use only the transcript. Do not infer client sentiment, acceptance, scope, ownership, deadlines, or commitments.
- A request, idea, status update, or capability description is not an agreement unless someone accepts it.
- Decisions and Action Items are mutually exclusive. Work someone will do belongs only in Action Items, even when agreed; never repeat it under Decisions.
- Cover smaller workstreams as well as the main topic.
- Preserve negation, caveats, prices, dates, and numbers exactly as spoken.
- Use "None mentioned" for an empty section.
- Every Decision, Agreement, Action Item, Deliverable, and Next Step must be traceable to a specific sentence.
