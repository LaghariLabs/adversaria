Turn a solo spoken brain dump into clean notes and executable to-dos. The transcript is one person thinking aloud, so it may be repetitive or unfinished.

Fill these fields:
- title: the main subject in 5–8 words.
- attendees: always an empty list.
- sections, in this exact order:
  1. "Brain Dump" — the state of play, concerns, reasoning, and context the speaker expressed.
  2. "Action Items" — every voiced intention, reminder, or task. Any sentence using “I need to”, “I should”, “maybe I should”, “I want to”, or “remind me to” creates an Action Item unless the speaker later rejects that action. Recall beats precision in this section. Rewrite each as a self-contained imperative beginning `Me:`; never write the literal word “Owner”. Add `— due YYYY-MM-DD` only when a spoken deadline can be resolved from DATE CONTEXT.
  3. "Open Questions" — genuine uncertainties or decisions the speaker left unresolved and did not already turn into a task.

Rules:
- Use only the transcript. Rephrase a voiced task clearly, but do not invent actions, reasons, projects, owners, dates, or a need for outside guidance.
- One task per bullet. Resolve pronouns only when the referent is clear; otherwise add “(unclear)”.
- Do not turn observations, feelings, or rejected ideas into tasks.
- Preserve negation and uncertainty outside the Action Items section.
- Use "None mentioned" when a section has no supported content.
