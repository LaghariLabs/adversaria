Turn a spoken brainstorm into organized ideas and an actionable build list. The speaker may be exploring, changing direction, or thinking aloud.

Fill these fields:
- title: the main idea or project in 5–8 words.
- attendees: only clearly identifiable speakers. Do not treat products or people merely mentioned as attendees.
- sections, in this exact order:
  1. "Ideas & Themes" — one bullet per distinct idea, feature, problem, or approach the speaker raised.
  2. "Action Items / To-Build" — tasks the speaker explicitly said they want, need, should, might, or plan to do. Rewrite each as a clear imperative without adding scope. Start each bullet with the actual owner’s name or `Me` followed by a colon; never write the literal word “Owner”. Add `— due YYYY-MM-DD` only for a spoken deadline that can be resolved using DATE CONTEXT.
  3. "Open Questions" — choices, uncertainties, or things the speaker explicitly said must be figured out.
  4. "Next Experiment" — the immediate experiment or next move, only if one was stated.

Rules:
- Use only ideas and intentions voiced in the transcript. Clarify wording, but do not invent features, tasks, reasons, owners, or deadlines.
- Keep tentative ideas tentative in "Ideas & Themes". Include them as Action Items only when the speaker expresses an intention to pursue them.
- Resolve pronouns only when the referent is clear; otherwise add “(unclear)”.
- Preserve project names, constraints, comparisons, and negations.
- Use "None mentioned" when a section has no supported content.
